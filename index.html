🔧 Inside the job-market pipeline

Employer-direct collection gives a different view from job boards, and conservative deduplication stops repeated vacancies inflating the counts.

Employer career sitesProvider adaptersRaw snapshotsValidationCleaningSkills & requirementsClassificationDeduplicationParquet martsDashboard
Collect and preserve
Ten dedicated adapters (Greenhouse, Lever, Workday, SAP SuccessFactors, Oracle HCM, WordPress Job Manager, Workable, Breezy HR, SmartRecruiters and Ashby) across a 51-employer registry, each handling its own pagination, detail endpoints and failure modes. Raw JSON or HTML is stored unchanged with timestamps and SHA-256 hashes, so cleaning logic can improve without recollecting history.
Standardise and extract
HTML is stripped, locations and workplace type normalised, and missing values handled explicitly. A curated taxonomy extracts languages, frameworks, databases, cloud platforms and tools, keeping the matched text as evidence, and splits minimum from preferred requirements.
Classify, explainably
Rule-based classification by seniority, role, domain, employment and workplace type comes first. Optional scikit-learn (TF-IDF + logistic regression) and Gemini layers only suggest values for unresolved vacancies, write to separate fields and never overwrite the canonical data.
Publish and validate
jobs.parquet is the one-row-per-vacancy source of truth, with job_skills and job_requirements tables beside it. Dashboard marts are checked for job keys and joins, and three data-quality reports cover transformation, skills and the dashboard contract. Every regex classifier was audited against live postings, and each confirmed bug was fixed and re-verified.
